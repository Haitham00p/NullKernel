 ============= WELCOME HOME =============
 This is your user directory: /home/Root

 Every *.c file under /bin is compiled at every boot
 into /bin/*.exe.  To build your own command:

      1. edit HELLO.C            (press Ctrl+S save, Ctrl+Q quit)
      2. run  ncc HELLO.C        (compiles right now, no reboot needed)
      3. run  hello               your new version runs

 To rebuild *everything*: type  reboot

 Have fun.  -Null
